# Engineering Starter

A first project to set up my C++ and Python engineering toolchain.

## Purpose
Practice compiling, debugging, and version-controlling small engineering
calculations before moving into the full EE/embedded roadmap.

## Setup
- C++: requires g++ (GCC)
- Python: requires Python 3, create a venv with `python3 -m venv venv`

## Usage
Compile and run the C++ example:
```
g++ cpp/src/main.cpp -o hello && ./hello
```
Run the Python example:
```
source python/venv/bin/activate python3 python/main.py
```
